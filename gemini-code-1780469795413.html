Predictive Modeling of Immune Responses to Influenza Vaccination

Forecasting individual antibody magnitude, breadth, and durability from the CMI-Flu Prediction Challenge dataset

Chayan Tronson, Brian Hill, Arvind Krish | Advisors: Barry Grant, Bjoern Peters | UC San Diego DSE MAS

THE PROBLEM & DATA

The Challenge

Flu vaccines offer incomplete, short-lived protection that varies widely between individuals based on age, genetics, and prior exposure. We built ML models to predict how a specific person responds to vaccination over time, benchmarked against a day-0 + demographics baseline to prove the added biological data carries real signal.

The Data

  • CMI-Flu Prediction Challenge (NIH-funded, ~11 GB), 3,960 participants
  • HAI serology (antibody titers), transcriptomics (RNA-seq + microarray), flow cytometry across multiple cohorts
  • Linked by participant ID across timepoints (Day 0, 28, 365)

Key Data Hurdles

  • High missingness; entire assays (BCR, microarray) unusable because absent from challenge set
  • Target strains sometimes absent from training (Task 4.2)
  • Gene IDs inconsistent across studies; cohort-level batch effects

METHODS / PIPELINE

Preprocessing

  • Pivoted HAI + transcriptomics to wide format (one row per participant)
  • Log2-transformed titers; encoded categoricals; scaled age
  • ComBat batch correction to remove study-specific technical variation
  • PCA compressed transcriptomics to 290 components capturing 95% of variance
  • Dropped sparse, leakage, and non-challenge features; engineered proxies, aggregates, deltas

Modeling

  • Framed all tasks as regression problems
  • Baseline: Linear Regression (demographics + Day 0 only) to establish a floor
  • H2O AutoML: up to 62 models per task (GBM, XGBoost, Deep Learning, Random Forest) combined into Stacked Ensembles
  • Evaluated with 5-fold cross-validation; Spearman correlation as the primary metric (rank-ordering participants)

KEY INSIGHTS

Day 0 titers are the dominant predictor. A participant's pre-vaccination HAI titer outweighed every other feature, often by an order of magnitude, across all tasks.

One model can serve many tasks. The Task 4.5 breadth model (trained on 1,200+ participants) was repurposed for strain-specific tasks by adding its predicted rise on top of each participant's Day 0 titer, beating individually trained models when data was sparse.

Age drives breadth of response. For Task 4.5, age was the single strongest feature, suggesting it shapes not just how strongly but how broadly a person responds.

Cross-strain responses are correlated. Participants who respond broadly also respond strongly to specific strains, pointing to a general immune-responsiveness trait.

Transcriptomics add signal when present. After PCA, Day 7 transcriptomic PCs consistently ranked in the top features for breadth, boosting one submission score by 9%.

Batch correction was essential for combining cohorts without mistaking technical artifacts for biology.

RESULTS

Final Kaggle Score

  • Private (62% of test data): 0.7581 — the official ranking metric
  • Public (38% of test data): 0.8033
  • A significant jump over the baseline and other CMI-Flu submissions

Per-Task CV Spearman

  • Task 4.2 (H3N2 magnitude, proxy target): 0.816
  • Task 4.6 (breadth, % of variants >= 40): 0.773
  • Task 4.5 (breadth, geomean): 0.754
  • Task 4.3 (Vic B magnitude): 0.721

Conclusion

Multi-omic data can be modeled to predict individual flu vaccine responses. AutoML ensembles beat demographic baselines, with baseline titers as the primary driver, laying groundwork for personalized vaccine administration.
